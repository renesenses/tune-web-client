# Messagerie : contrôle visuel du 29/10/2026

Captures Safari du vrai composant Svelte et des jetons existants, sur une instance Vite locale. Données de test fictives ; API interceptée dans le banc, aucune sortie audio. Clair : `clear-white`, sombre : `midnight-orange`. Les captures sont recadrées pour retirer le navigateur et ses onglets.

Elles prouvent la présentation du composant, pas la livraison ni un échange authentifié entre deux comptes cloud. Les originaux et le banc sont dans `~/DEV/coordination/captures-messagerie/` et `preuves-messagerie-2910/`. Un iframe de largeur 390 px a aussi permis de constater liste OU fil et le retour ; aucun clavier de téléphone physique testé.
